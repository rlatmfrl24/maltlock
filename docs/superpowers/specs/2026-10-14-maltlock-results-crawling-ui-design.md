# 몰트락 통합 라이브러리·크롤링 UI

사용자가 승인한 설계: 공통 사이트 선택과 수집결과/크롤링 두 탭으로 통합한다. 기본 화면은 수집결과이고, 6개 사이트는 3열×2행 버튼으로 저장 건수와 함께 표시한다. 사이트 선택이나 탭 전환은 브라우저를 이동하지 않는다.

크롤링 시작은 저장된 사이트 URL로 현재 탭을 이동하고 새 문서의 준비를 확인한 뒤 기존 파싱·저장을 수행한다. 단일 페이지, 기존 페이지 범위·랭킹·플랫폼 순회를 지원한다. 모든 종료 상태에서 해당 사이트의 누적 수집결과를 표시하고 실행 요약과 실패 원인을 남긴다. 기존 현재 페이지 옵션은 단일 페이지로 이름을 바꾼다.

밝은 중립 배경, 기존 로고·녹색 강조색, 제목과 큰 비율 유지 썸네일을 사용하는 라이브러리 화면으로 정리한다. 600px 미만 1열, 이상 2열이다. 결과 목록은 남은 높이를 사용한다. 키보드 탭 전환·포커스 복귀·로딩·빈 결과·오류 상태를 제공한다.

파서·저장·중복·출처 필터·캐시·사생활 모드·링크·삭제의 기존 계약과 미커밋 변경을 보존한다. 실행 중 사이트·설정·삭제 변경은 잠그되 화면 탭은 이동할 수 있다. 수동 페이지 이동을 덮어쓰거나 다른 탭을 파싱하지 않는다. 새 의존성·DB 마이그레이션·검색·정렬은 추가하지 않는다.

완료 기준은 사용자의 시작 버튼에서 실제 사이트 이동·파싱·저장·결과 표시까지 도달하고 IndexedDB 읽기로 확인하는 것이다. 자동화 검증은 이를 보조한다.
